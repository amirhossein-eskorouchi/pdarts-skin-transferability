# Results

This repository distinguishes immutable publication records from future
reproduction outputs.

## Canonical publication record

`results/publication_record/` contains machine-readable values transcribed from
the manuscript record.

These values are:

- manuscript-reported;
- not regenerated by the maintained package;
- preserved with publication-location fields; and
- protected by provenance validation.

Generated Markdown views are stored in
`results/publication_record/tables/`.

## Reproduction outputs

Future maintained workflows must write only below:

    results/reproduction/

A reproduction result must record its experiment configuration, Git revision,
environment, split-manifest hash, seed, and result provenance.

## Interpretation rule

A publication value is not an exact reproduction merely because a historical
checkpoint or log contains a similar number.

A reproduced value must be created by an explicitly documented rerun.
