# Source lineage

This directory documents how scientifically relevant source files from the
private P-DARTS research archive are evaluated before they enter the public
repository.

The archive is evidence, not a ready-to-publish repository. Files are not
copied merely because they exist in the archive. Each candidate must receive a
documented identity, origin, scientific role, disposition, and public-release
decision.

## Batch 3 objectives

Batch 3 will:

1. identify the archive's human-authored source files;
2. distinguish project-specific code from upstream P-DARTS/DARTS code;
3. distinguish maintained reconstruction from historical implementation;
4. record local modifications to upstream-derived files;
5. preserve scientifically relevant historical behavior without presenting it
   as the maintained interface;
6. block publication of source files with unresolved ownership, licensing,
   privacy, or provenance;
7. exclude generated bytecode, checkpoints, arrays, logs, local datasets, and
   workstation-specific runtime material; and
8. produce a machine-readable source-lineage register.

## Planned public code areas

The repository uses three distinct code boundaries:

- `src/`: maintained, reusable implementation developed or reconstructed for
  this repository;
- `scripts/`: maintained command-line workflows and repository utilities; and
- `reference_implementations/`: clearly labeled historical research code
  retained only when its provenance and public-release status permit it.

No historical file becomes maintained merely by being copied into the
repository.

## Evidence hierarchy

Source-lineage decisions use the following evidence, in descending order:

1. file content and internal documentation;
2. comparison with identifiable upstream source;
3. successful experiment configurations and run ledgers;
4. thesis and manuscript method descriptions;
5. filenames and archive placement; and
6. inference from neighboring files.

An inference must be labeled as an inference. Unknown provenance must remain
unknown until evidence resolves it.

## Current status

The lineage framework is established, but no source file has yet been migrated
from the private archive. Subsequent steps will inventory and review source
candidates before any selective extraction occurs.
