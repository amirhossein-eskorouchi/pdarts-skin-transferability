# Publication Record

This directory will contain compact, machine-readable records of results
explicitly reported in the associated study.

Publication-record values are preserved separately from:

- exploratory search outputs;
- incomplete evaluation sweeps;
- failed runs;
- restarted runs;
- development batch-size studies;
- generated software demonstrations;
- future reproduction results.

A publication-record value is not automatically considered regenerated
by the maintained repository.

Each result table must identify:

- the source document;
- the source table or figure;
- task type;
- source dataset;
- target dataset;
- search method;
- search depth;
- evaluation depth;
- image resolution;
- replication or aggregation basis;
- metric definition;
- reported value;
- provenance status.
