# Reference implementations

This directory is reserved for selectively published historical research code.

Files placed here are reference evidence, not the maintained software interface.
They may document the behavior used during the original experiments, including
legacy assumptions or compatibility constraints.

A file may enter this directory only after:

1. its archive path and SHA-256 have been recorded;
2. its project-specific or upstream-derived origin has been assessed;
3. its public-release status has been approved;
4. local paths, credentials, private data references, and sensitive identifiers
   have been reviewed;
5. any deviation from the archived file has been documented; and
6. its relationship to the maintained implementation has been stated.

The private PDARTS archive, model checkpoints, NumPy intermediates, datasets,
logs, manuscripts, and nested source archives do not belong here.

No historical source files have been migrated at this stage.
